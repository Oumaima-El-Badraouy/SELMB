اتصل بنا

املأ النموذج أدناه ثم اضغط «إرسال الرسالة». تُحفظ الرسائل على الخادم في الملف backend/data/contact-messages.json (يتطلّب تشغيل واجهة API محلياً، مثلاً npm run dev في مجلد backend). إن ظهرت «Unauthorized»، أعد تشغيل الخادم بعد التحديث وتأكد أن العنوان ينتهي بـ /api/v1.

عنوان API (إن لزم)
مثال: http://127.0.0.1:4000/api/v1

للإبلاغ داخل التطبيق بعد تسجيل الدخول: دخول ثم «إبلاغ عن مشكلة».
